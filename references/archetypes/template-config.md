# 类型：template-config（脚手架 / starter / 基础设施即代码 / dotfiles / 配置集合）

## 识别
topics/README 含 template/boilerplate/starter；cookiecutter/copier；`.tf`、Helm、k8s、ansible；dotfiles。

## 什么算好
- **一键可用**：按 README 生成/部署后，产物能直接跑通；有最小示例
- **默认值安全**：密钥不内置、权限最小、公网暴露需显式开启
- **可定制且不混乱**：参数少而清晰，更新模板后下游能合并（有升级路径）
- 依赖/版本固定，说明了适配的版本范围
- 说明了"该用与不该用"的场景

## 必读文件
README 的使用步骤；模板入口与参数定义；一个生成产物；默认配置（安全相关项）；CI 是否对模板做生成测试。

## 类型特有检查
- 生成/部署后的产物是否经过 CI 验证（模板最常见的问题是"模板自己都跑不通"）
- 默认配置：端口、鉴权、存储加密、IAM 权限、示例密码
- IaC：状态存储与锁、环境隔离、销毁是否安全
- 升级路径：下游如何同步模板更新

## 类型特有红旗
- 内置示例密钥/弱口令；默认全开放安全组/公网数据库
- 模板依赖未固定，数月后无法生成
- 无任何生成/部署测试

## 维度解释
E +3、F +3；D = "生成物能否直接跑通"；H 看参数设计与可扩展点。

## 同类对手怎么选
同栈的主流 starter/模板；比较开箱即用程度、默认安全性、更新机制、社区使用度。
