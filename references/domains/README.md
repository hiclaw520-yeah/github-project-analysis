# 领域补充清单（按线索选读，不是必读）

领域清单只补充"这个领域特有的正确性与风险"，**不替代**类型手册与通用九维。
`classify_repo.py` 的"领域线索"命中 ≥2 次才建议读对应清单；一个项目可以命中多个领域。

| 领域 | 典型线索 | 文件 |
|---|---|---|
| 量化 / 交易 / 行情 / 选股 / 回测 | akshare/tushare/baostock/yfinance/ccxt、回测、K 线、A 股 | `quant-trading.md` |
| LLM / Agent / RAG / MCP / 多智能体 | openai/anthropic/langchain/mcp/embedding/agentic | `ai-agent-llm.md` |
| 安全 / 双重用途（逆向、渗透、爬虫、绕过、反检测、漏洞利用） | decompile/ghidra/exploit/pentest/scraper/anti-bot/bypass | `security-dual-use.md` |

## 遇到清单里没有的领域怎么办
不要硬套。按这个最小模板现场补一份"领域检查"，写进报告的"领域专项"一节：
1. **这个领域里"做对"的硬标准是什么？**（正确性：规则、标准、合规；例如金融的交易规则、医疗的临床指南、数据工程的幂等与数据质量、Web3 的重入与权限）
2. **领域里最常见的 3 个致命错误是什么？** 去代码里逐个核对
3. **领域特有的法律/合规/伦理风险？** 有无声明与边界
4. **领域特有的数据/依赖风险？** 数据来源条款、外部服务可用性、成本
把这四点各写一句结论即可，并标注"来自现场补充，非固定清单"。
